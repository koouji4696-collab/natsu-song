# なつのうた｜セットアップ手順（スプレッドシート版）

小学生サマースクール「AIで言葉を音楽にする」授業用のWebアプリです。
Cloudflareは使いません。**Googleスプレッドシート＋GitHub Pages** だけで動きます。録音処と同じ構成です。

- **生徒用画面**（班のiPad）… 声・付箋の写真で言葉を集める
- **教員用画面**（先生のPC・プロジェクター）… 集まった言葉を受信し、Suno用の歌詞とスタイルを作る

| ファイル | 置き場所 | 役割 |
|---|---|---|
| `gas-code.gs` | スプレッドシートのApps Script | データ保管とAPIキーの保管 |
| `index.html` | GitHub | 画面（生徒用・教員用の両方） |
| `config.js` | GitHub | 接続先の設定。ここを書き換える |

---

## ⚠️ 最初に

**APIキーは絶対にGitHubに置かないでください。** GitHub Pagesは静的サイトなので、書いたキーは誰でもソースを見れば読めます。この手順ではキーをGAS側のスクリプトプロパティに置くので、外には出ません。

---

## 手順1：スプレッドシートとGASを用意する（15分）

1. Googleドライブで新しいスプレッドシートを作成。名前は `なつのうた_データ` など
2. メニューの **拡張機能 → Apps Script** を開く
3. 既定の `function myFunction() {}` を全部消して、`gas-code.gs` の中身を貼り付け
4. 左の歯車 **プロジェクトの設定** → 下の方の **スクリプト プロパティ** → **スクリプト プロパティを追加** で2つ登録

   | プロパティ | 値 |
   |---|---|
   | `ANTHROPIC_API_KEY` | Claude ConsoleのAPIキー |
   | `APP_TOKEN` | 任意の英数字（例 `natsu2026school`） |

5. **保存**

---

## 手順2：ウェブアプリとして公開する（5分）

1. 右上の **デプロイ → 新しいデプロイ**
2. 歯車マーク → **ウェブアプリ** を選択
3. 設定は次の通り

   | 項目 | 値 |
   |---|---|
   | 説明 | なつのうた API v1 |
   | 次のユーザーとして実行 | **自分** |
   | アクセスできるユーザー | **全員** |

4. **デプロイ** → 初回は権限の確認が出るので、**詳細 → （プロジェクト名）に移動 → 許可**
5. 表示された **ウェブアプリのURL**（`/exec` で終わる）をコピーして控える

> 「アクセスできるユーザー：全員」は、児童のiPadからログインなしで使うために必要です。URLを知らない人はアクセスできませんし、`APP_TOKEN` でも保護しています。

---

## 手順3：動作確認（2分）

控えたURLをブラウザのアドレスバーに貼って開いてください。

```
{"ok":true,"message":"なつのうた API は動いています"}
```

と表示されれば成功です。エラーが出る場合は手順2の設定を見直してください。

---

## 手順4：GitHubに画面を置く（10分）

1. GitHubで新規リポジトリを作成（名前は `natsu-song` など）
2. `index.html` `config.js` `README.md` をアップロード
3. `config.js` を編集（GitHub上で鉛筆マークから直接編集できます）
   - `API_BASE` … 手順2で控えたGASのURL（`/exec` まで含める）
   - `APP_TOKEN` … 手順1で決めた文字列と同じもの
4. **Settings → Pages** → Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
5. 1〜2分待つと公開されます

| URL | 画面 |
|---|---|
| `https://＜ユーザー名＞.github.io/natsu-song/` | 生徒用 |
| `https://＜ユーザー名＞.github.io/natsu-song/#teacher` | 教員用 |

---

## 手順5：通しで確認

1. 教員用を開き、「🪄 デモデータ一括投入」を押す → 29名分が入る
2. スプレッドシートに `state` シートができ、`g1`〜`g5` の行が増えていることを確認
3. 生徒用を別の端末で開き、1班を選ぶ → デモの言葉が見える
4. 生徒用で言葉を追加 → 10秒ほどで教員用に出る
5. 付箋を書いて写真を撮る → 読み取られる
6. 教員用で「🎵 歌詞をコピーしてSunoを開く」 → 曲を作る → URLを登録 → 生徒用に「▶ うたを きく」が出る

---

## うまくいかないとき

教員用の上部に「⚠️ 通信エラー：」とメッセージが出ます。

| メッセージ | 原因と対処 |
|---|---|
| トークンが違います | `config.js` の `APP_TOKEN` とスクリプトプロパティが不一致 |
| ANTHROPIC_API_KEY が…未設定です | 手順1-4のプロパティ名を確認（スペルミスに注意） |
| Failed to fetch | `API_BASE` のURLが違う。`/exec` で終わっているか確認 |
| model が見つからない | `gas-code.gs` の `MODEL` を、Claude Consoleのモデル一覧にある名前に変更 |

コードを直したら、**必ず「デプロイ → デプロイを管理 → 鉛筆マーク → バージョン：新バージョン → デプロイ」** をしてください。保存しただけでは反映されません（URLは変わりません）。

---

## 授業当日の流れ

1. 先生：教員用画面を開いてプロジェクターに投影
2. 生徒：各班のiPadで生徒用URLを開き、班を選ぶ（QRコードを黒板に貼っておくと速い）
3. 前半：班ごとに言葉を集める → 先生が各班タブでSunoへ → 曲URLを登録 → その場で聴く
4. 後半：フィナーレタブでパートを調整 → 全体曲を生成 → URLを登録 → 全員で聴く

授業が終わったら、教員用の「🗑️ 全消去」でデータを消せます。次回も同じURLがそのまま使えます。

---

## 注意点

- **前日に、当日と同じ校内Wi-Fi・同じiPadで表示確認をしてください。** 画面は cdn.tailwindcss.com と unpkg.com から部品を読み込むので、学校のフィルタリングがこれらを止めていると真っ白になります。
- 児童の氏名など個人が特定される情報は入力しない運用にしてください。
- 同期の間隔は、教員用8秒・生徒用15秒にしてあります。GASには1日の実行時間の上限があるため、これ以上速くすると授業の途中で止まる可能性があります。すぐ反映させたいときは「🔄 いま受信」を押してください。
- Claude APIの呼び出しは1日300回までに制限してあります（`gas-code.gs` の `DAILY_LIMIT`）。
- 音声入力はSafari／Chromeの機能を使います。iPadでは初回にマイクの許可を求められます。
